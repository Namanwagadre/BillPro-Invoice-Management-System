# BillPro – Invoice Management System

A Django-based Invoice Management System that helps users manage invoices efficiently.

## Features

- User Registration, Login and Logout
- Create, View, Update and Delete Invoices
- Search Invoices by Customer Name or Invoice Number
- Filter Invoices by Paid and Unpaid Status
- Dashboard with Invoice Statistics
- Download Invoices as PDF
- User-wise Invoice Data Security
- Form Validation

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- ReportLab

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Namanwagadre/BillPro-Invoice-Management-System.git
   ```

2. Open the project folder:

   ```bash
   cd BillPro-Invoice-Management-System
   ```

3. Create a virtual environment:

   ```bash
   python -m venv my_env
   ```

4. Activate the virtual environment (Windows):

   ```bash
   my_env\Scripts\activate
   ```

5. Install dependencies:

   ```bash
   pip install django reportlab
   ```

6. Run migrations:

   ```bash
   python manage.py migrate
   ```

7. Start the development server:

   ```bash
   python manage.py runserver
   ```

8. Open in your browser:

   `http://127.0.0.1:8000/`
